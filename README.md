# ScriptSync data

Public data for the ScriptSync mod (by Pilsjes/Dylan). Every ScriptSync mod reads these files every 2 minutes. Only the owner changes them from in game.

- `safelist.txt` - Safelist tab. One player per line: `Name|yyyy-mm-dd|text` (text optional).
- `tagged.txt` - Tagged tab. One player per line: `Name|yyyy-mm-dd|tag`.
- `ranks.txt` - Custom ranks. One player per line: `Name|yyyy-mm-dd|color:rank`, e.g. `Pilsjes|2026-11-09|red:OWNER`.
